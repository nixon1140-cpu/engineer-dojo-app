# 一人前エンジニア道場（Ichininmae Engineer Dojo）

## プロジェクト概要
- **名前**: 一人前エンジニア道場
- **ゴール**: AI時代に未経験エンジニアが「一人称で」活躍できるようになるための体系的学習プラットフォーム
- **コンセプト**: 「AIが書く時代、人間は『判断』で価値を出す」。コードを書く速さではなく、要件の言語化・設計の妥当性判断・AI生成コードの検証・現場の調整力を鍛える

## 技術スタック
- **フレームワーク**: Hono 4 + TypeScript + Vite + Cloudflare Pages
- **レンダリング**: hono/jsx-renderer（SSR）
- **スタイル**: Tailwind CSS（CDN）
- **アイコン**: Font Awesome 6
- **データ永続化**: localStorage のみ（静的サイト）
  - `dojo-progress-v1`: レッスン完了・クイズ・シナリオ進捗
  - `dojo-skills-v1`: スキルチェックリスト
  - `dojo-daily-quiz-v1`: デイリークイズ履歴・ストリーク
  - `dojo-reviews-v1`: 忘却曲線復習リスト
- **SQL**: sql.js 1.10.2 WASM（ブラウザ内SQLite）
