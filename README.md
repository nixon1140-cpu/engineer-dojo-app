# 一人前エンジニア道場（Ichininmae Engineer Dojo）

## プロジェクト概要
- **名前**: 一人前エンジニア道場
- **ゴール**: AI時代に未経験エンジニアが「一人称で」活躍できるようになるための体系的学習プラットフォーム
- **コンセプト**: 「AIが書く時代、人間は『判断』で価値を出す」。コードを書く速さではなく、要件の言語化・設計の妥当性判断・AI生成コードの検証・現場の調整力を鍛える

## 主な機能

### 1. カリキュラム（9トラック / 27レッスン）
| カテゴリ | トラック | 内容 |
|---|---|---|
| 技術 | **プログラミング基礎（入門）** | 未経験者の第一歩。変数と計算、条件分岐、関数と配列、エラーメッセージの読み方 |
| 技術 | フロントエンド開発 | レンダリングの仕組み、AI生成コードのレビュー、状態管理設計、フォーム設計 |
| 技術 | バックエンド開発 | REST API設計、冪等性、認証・認可、セキュリティコードレビュー |
| 技術 | インフラ・運用 | 安全な本番変更（expand & contract）、障害初動、ログ設計 |
| 技術 | データベース設計 | 要件からのテーブル設計、スナップショット、N+1問題 |
| ビジネス | マーケティング視点 | ファネル分析、イベント計測設計 |
| ビジネス | 経営視点 | 技術的負債の経営的説明、Build vs Buy |
| ビジネス | 営業視点 | 要件の深掘り（5 Whys）、見積もりと不確実性の伝え方 |
| AI時代 | AI時代のエンジニアリング | AI生成コードの検証、要件の言語化、設計判断のフレームワーク |

各レッスンには以下が含まれる:
- 導入（なぜ学ぶか）→ 本文 → 重要ポイント
- 理解度チェッククイズ（選択式・即時フィードバック付き）
- **ヒント機能**: クイズ・コードレビュー演習には「ヒントを見る」の折りたたみ。答えを直接見せず、考え方の方向性だけを示す設計
- コードレビュー演習（AI/他人が書いたコードの問題点を指摘する実践形式）
- **コーディング演習（24題）**: ブラウザ内エディタで実際にコードを書き、テスト実行で合否判定。ヒント・模範解答付き
  - 入門: 消費税計算、年齢別料金、配列加工（filter/map）
  - FE: CSSプロパティ分類、HTMLエスケープ、URLクエリ構築、フォームバリデーション
  - BE: ステータスコード対応表、冪等キー判定、認可チェック、SQLi兆候検出
  - インフラ: マイグレーション手順、障害報告テンプレート、ログマスキング
  - ビジネス: ファネル計算、イベント構築、技術的負債の利息、Build vs Buy、要件深掘り、見積もり幅
  - AI時代: 危険文字チェック、検索結果表示の受け入れ条件、設計案スコアリング
- **SQL演習（5題）**: ブラウザ内SQLite（sql.js WASM）で実際のSELECT文を実行・採点
  - db-1-1: JOIN + GROUP BY でユーザー別売上集計
  - db-1-2: JOIN で N+1 問題を1クエリに解消
  - db-2-1: SELECT基礎（WHERE / ORDER BY / LIMIT で上位3件）
  - db-2-2: 集計とGROUP BY（COUNT + HAVING でステータス別件数）
  - db-2-3: JOINとLEFT JOIN（注文0件ユーザーを含む全ユーザー集計。COUNT(o.id)の落とし穴も）
  - 全模範解答は sqlite3 で実行検証済み

### 2. 実践シナリオ（8件のロールプレイシミュレーション）
「教室では学べない現場の判断」を一人称ストーリーで体験:

1. **初日のコードリーディング** — 他人が書いたコードを読む
2. **ふわっとした要件の翻訳** — 他人の要件を正しく理解する
3. **チームのルールと自分の流儀** — チームの既存ルールに従う
4. **はじめてのコードレビュー** — 自分のコードを人間にレビューされる
5. **指摘への対応方針を調整する** — 指摘内容について相手と調整する
6. **バグ修正の優先順位づけ** — 納期・品質・影響範囲を意識して修正する
7. **本番環境の緊急パッチ** — 他人が利用する本番環境を安全に変更する
8. **選べない技術との闘い** — 自分では選べない技術や仕様に対応する

各選択は3段階評価（◎最善 / ○及第点 / △改善余地）で、詳細なフィードバックとまとめ（debrief）付き。スコアに応じて「入門→見習い→中堅→一人前」の称号を付与。

### 3. コーディング演習ランナー
- ブラウザ内のテキストエディタでコードを記述（Tabキーインデント対応・スマホでも編集可）
- **Web Worker（別スレッド）でユーザーコードを実行**: 無限ループを書いても画面が固まらず、5秒でタイムアウトして `worker.terminate()` で強制停止。タイムアウト時は初学者向けの日本語ガイド（ループ条件・カウンタ更新の確認ポイント）を表示
- Worker 未対応環境では同期実行（Function コンストラクタ）に自動フォールバック
- テストごとの期待値/実際値の差分表示、構文エラーの検出、ヒント・模範解答の段階的開示
- 全テスト合格で進捗に記録

### 3.5 SQL演習ランナー（ブラウザ内SQLite）
- sql.js（SQLiteのWASMビルド）をCDNから読み込み、完全にブラウザ内で動作
- 各問題はテーブル定義（schemaSql）と初期データ（seedSql）付き。折りたたみで確認可能
- 「実行して採点」でユーザーのSQLを実行し、模範解答SQLの結果（カラム構成・行内容・順序）と自動比較
- 結果はテーブル形式で表示し、不一致時は期待結果との差分を提示。ヒント・模範解答も段階的に開示

### 4. 進捗ダッシュボード
- 完了レッスン数・正解した演習数・クリアシナリオ数のサマリー
- トラック別進捗バー
- シナリオ成績一覧
- データはブラウザのlocalStorageに保存（サーバー不要）

## データアーキテクチャ
- **コンテンツ**: TypeScriptファイルとして静的にバンドル（`src/data/`）
  - `src/types.ts` — Track/Chapter/Lesson/Quiz/CodeExercise/CodingChallenge/SqlChallenge/Scenario の型定義
  - `src/data/tracks/beginner.ts` — プログラミング基礎（入門）トラック
  - `src/data/tracks/tech.ts` — 技術系4トラック
  - `src/data/tracks/business.ts` — ビジネス系3トラック
  - `src/data/tracks/ai-era.ts` — AI時代トラック
  - `src/data/scenarios.ts` — 実践シナリオ8件
- **進捗データ**: ブラウザのlocalStorage（`dojo-progress-v1`）に保存。サーバーDB不使用
- **ストレージサービス**: 未使用（静的コンテンツ配信のみ）

## 使い方
1. **未経験の方はまず「プログラミング基礎（入門）」トラックから**（トップページの導線または `/tracks/beginner`）
2. トップページの**学習ロードマップ**で全体の位置づけを確認（この道場はSTEP1-2の「入口と土台」。STEP3以降は自分で作る実践ステージ）
3. `/tracks` で興味のあるトラックを選び、レッスンを読み進める
4. レッスン内のクイズ・コード演習・SQL演習で理解度を確認（詰まったらヒント→模範解答の順で）
5. 分からない用語は `/glossary` の用語集で確認
6. 「完了にする」ボタンで進捗を記録
7. `/scenarios` で実践ロールプレイに挑戦し、現場の判断力を体験
8. `/dashboard` で全体の進捗を確認
